Payment API
API RESTful para gerenciamento de clientes, cartões e pagamentos, desenvolvida com C# e .NET 8. O projeto tem como objetivo simular um cenário próximo ao encontrado em sistemas reais de pagamentos, explorando arquitetura, regras de negócio, validações, persistência, testes e evolução da aplicação.

Tecnologias e conceitos:

C# / .NET 8
ASP.NET Core Web API
Clean Architecture
SOLID
Entity Framework Core
SQL Server
Design Patterns
API Versioning
Swagger / OpenAPI
xUnit
Docker
RabbitMQ (conforme a evolução do projeto)

Objetivo: demonstrar não apenas a implementação de um CRUD, mas a construção e evolução de uma API seguindo práticas utilizadas em ambientes profissionais.
